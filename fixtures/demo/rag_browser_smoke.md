# TVAC-03 열모델 입력 근거

## 적용 범위

이 합성 시연 문서는 DORI-01, configuration TVAC-03, run RUN-DEMO-01에만 적용한다.

## 상관해석 입력

TVAC-03 열모델 상관해석에는 부품별 소산전력 지도와 각 열원의 위치 식별자가 필요하다. 전력 값은 시험 시점의 운용 모드와 연결하고, 열원 위치는 현재 형상 기준선과 추적되어야 한다.

## 검토 경계

이 문서는 문서 업로드, 파싱, 청킹과 검색 계보를 검증하기 위한 공개 합성 fixture다. 공식 시험 승인이나 검증 종결 근거로 사용할 수 없다.
