# TVAC-03 열모델 입력 근거 — 상세 설정 합성 시연

> 이 문서는 DoriLab의 문서 업로드, 파싱, 청킹, 검색과 Source Review 연결을 보여주기 위한 공개 합성 입력이다. 기관 표준 원문, 실제 시험 자료, 고객 자료 또는 공식 검증 근거가 아니다.

## 적용 범위

이 합성 시연 문서는 unit `DORI-01`, configuration `TVAC-03`, run `RUN-DEMO-01`의 BM1 자료 검토 흐름에만 사용한다.

## 상관해석 입력

TVAC-03 열모델 상관해석에는 부품별 소산전력 지도와 각 열원의 위치 식별자가 필요하다. 전력 정보는 시험 시점의 운용 모드와 연결하고, 열원 위치는 현재 형상 기준선에서 추적할 수 있어야 한다.

검색 확인 문구: `component dissipation power map`

## 추적 조건

등록한 문서 원문, 파서 receipt, 선택된 청크와 retrieval receipt를 같은 검토 실행에 연결한다. Source Review에는 서버가 선택한 현재 청크만 전달하며, 모델 원출력과 Validator 결과는 별도로 보존한다.

## 사용 경계

이 문서에는 실제 측정값, 기관별 채택 조항, 승인 결과 또는 미리 정한 모델 판정이 없다. 모델의 검토 초안은 사람이 별도로 판단해야 하며 시험 실행, Gate 승인과 검증 종결을 자동으로 확정하지 않는다.
