# 별도 검토용 지시문 초안

1차 입력: 질문, 제안, 관측, 원문 근거, 출력 계약. 작성자의 expected/rationale은 제외한다.

같은 자료만으로 자신의 결론과 필요한 근거를 작성한다. 출처가 없는 결론, 가정으로 채워야 하는 공백, 여러 정답 가능성, 부적절한 관측 범위를 식별한다.

2차 입력: 작성자와 1차 검토자의 두 결과.

불일치를 사실 추출 / source 적용 / 수치·단위 / 제안 해석 / 업무 정책 / 출력 형식으로 분류한다. 이견의 위치와 필요한 확인을 짧게 적는다. 자기 confidence 숫자만으로 정답 승인을 결정하지 않는다.

가독성 확인: (a) 무엇을 판단하는지, (b) 근거가 무엇인지, (c) 왜 결론이 그렇게 나오는지, (d) 무엇을 해야 하는지 각각 한 문장으로 답할 수 있는가? 불가능하면 READABILITY_REWORK.

자동 결과는 AUTO_CHECKED_CANDIDATE다. 사람의 원문 검토와 label approval은 별도다.
