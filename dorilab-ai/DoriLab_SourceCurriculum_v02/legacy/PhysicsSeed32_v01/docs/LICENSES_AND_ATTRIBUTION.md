# Source attribution, reuse notices and changes

This package contains source metadata, attributed paraphrases, and newly constructed synthetic review scenarios. It does not contain downloaded original PDF/PPTX files, raw test data, or the cited authors' endorsement of the generated scenarios.

- Source: https://ntrs.nasa.gov/citations/19720011230
- Original-file URL: https://ntrs.nasa.gov/api/citations/19720011230/downloads/19720011230.pdf
- NTRS rights statement recorded: **Work of the US Gov. Public Use Permitted.**
- Catalog date: 1971-03-01. PDF title/report page text: March 1972. This discrepancy is retained, not silently reconciled.
- Adaptation: selected prose principles were paraphrased in English and Korean; hypothetical review proposals and counterfactual evidence were constructed. Scenario measurements and approval records are not original Apollo test observations.

## Other registered sources

Each source retains its exact recorded rights statement in `sources/source_manifest_v01.json`. NTRS “Public” distribution, “Public Use Permitted”, and “Work of the US Gov. Public Use Permitted.” are recorded separately. They are not silently replaced with one universal license classification.

The Garmendia/Anglada 2022 paper's accessible publisher PDF states CC BY 4.0; no Seed32 cases have been derived from it in this package. Presentations and contractor/conference papers retain their particular metadata and copyright notices. The source landing page and native document are the reference for source-specific attribution.

## Code and annotation handling

The accompanying utility code is generated for use and adaptation in the DoriLab project. Source licenses and notices continue to apply to the attributed source-derived portions. No model weights, third-party font files, private customer records, or licensed full-text source copies are included.

The candidate action labels and Korean review explanations were machine-authored and checked for internal consistency. `review_decisions.csv` is intentionally pending until an actual human review is recorded.
