# 출처와 귀속

이 패키지는 사용자가 제공한 DoriLab PhysicsSeed32 v0.1과 통합개발계획 Rev.2.0을 기준으로 확장한 자료이다. 이전 패키지는 `legacy/PhysicsSeed32_v01`에 보존했다. 원본 파일 해시는 `reports/INPUT_PROVENANCE.json`에 있다.

Wijker, Ellenbroek, de Boer (2015), CEAS Space Journal, DOI 10.1007/s12567-015-0086-0은 CC BY 4.0으로 공개된 논문이다. 기존 사례는 이 논문의 원리를 요약하고 별도 가상상황으로 변형했다. 원저자가 DoriLab 라벨이나 정답 행동을 작성하거나 검증한 것은 아니다. 라이선스: https://creativecommons.org/licenses/by/4.0/

NASA NTRS 자료는 각 상세 페이지의 실제 공개·권리 표시를 SOURCE_REGISTER와 source_manifest에 기록했다. 모든 NASA 호스팅 문서에 동일한 저작권 조건을 부여하지 않았다. FL-03과 SW-03의 사용권은 추가 확인 대상으로 남겼다.

문헌의 사실 요약, DoriLab이 설계한 가상 상황, 엔지니어가 검토할 정답 후보는 별도 항목이다. 원저작물의 라이선스와 출처 정보를 이 패키지의 코드 또는 모델 전체에 임의로 확장 적용하지 않는다. 새로 제공한 코드와 가상 사례는 이 작업을 위한 생성 산출물이며, 최종 이용·공유 방식은 사용자가 결정한다.

공식 라이브러리의 설치·API 예시는 문서의 기술 참고자료를 따른다. 해당 라이브러리와 모델의 가중치·패키지·폰트는 ZIP에 포함되지 않았다.
