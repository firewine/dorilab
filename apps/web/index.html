RAG 검토 범위 설정

최대 20 MiB. PDF 텍스트층·UTF-8 텍스트·Markdown·JSON·CSV를 지원합니다. OCR·표·그림 의미 해석은 포함하지 않습니다. 파싱 완료는 내용·적용성 승인과 다릅니다. RAG 검색에는 권리·판본·채택·적용성 검사를 통과한 검색 자료만 사용합니다.

100문항 세트는 ‘학습 사례 작성·검토’ 탭에서 파일 하나로 자동 분리·등록할 수 있습니다. 이미 저장한 학습용 Markdown은 아래 등록부에서 문항별 검토 목록에 등록하십시오.

문항 세트를 올리면 파일에 적힌 유형·출처 묶음·학습/평가 구분으로 자동 분리합니다. 검토 책임자·승인권자가 질문·정답·오답을 확인하고 한 문항씩 승인하거나 기각합니다. Local LLM 호출·데이터 내보내기·모델 학습은 실행하지 않습니다.

질문·정답·오답 세트 등록

문항을 다시 입력하지 않고 원본 파일과 문항별 검토 기록을 서버에 보존합니다.

DoriLab 100Q 핸드오프 v1 형식 · UTF-8 · 최대 20 MiB. 다른 형식은 오류를 표시하고 임의 분리하지 않습니다.
파일 권리·판본 정보 (선택)

모든 문항은 미검토로 시작합니다. 원 답안·오답·검토 메모와 승인 시 수정한 답안을 따로 보존합니다. 평가 문항과 오답은 정답 학습 대상으로 사용하지 않습니다.

문항별 검토 목록

파일의 원문 확인 범위와 사람의 문항 승인을 구분합니다. 논문 원문·사용 권리 검증과 GPU 학습은 별도 단계입니다.

파일을 등록하면 여기에서 한 문항씩 검토할 수 있습니다.
